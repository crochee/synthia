The Error enum — the single cross-crate error type for Synthia, used by every workspace member.

§Design: thiserror enum + boundary adapter

Two-layer split (the axum error-handling pattern):

  • Domain layer (this crate) — Error owns the failure taxonomy: one variant per failure mode with pure payload fields. [thiserror::Error] generates Display from the per-variant #[error("...")] format strings and std::error::Error::source from the #[from] / #[source] payload fields. No hand-written message methods, no mirror ErrorKind classifier. The stable snake_case wire code belongs to the transport layer (synthia_server::api::error), not to this enum.
  • Transport layer (synthia-server) — the ApiError adapter maps a variant to an HTTP status and a safe JSON envelope, and logs the full chain (operator-only detail). See synthia_server::api::error.

Prefer the helper constructors (Error::not_found, Error::validation, …) over constructing variants directly.
