Sensitive information encryption / redaction primitives.

Canonical location for Sensitive and SensitiveData. Previously lived in synthia-telemetry; moved here because it is a cross-cutting domain capability unrelated to OpenTelemetry pipelines.

redact_partial
Partially redact a string for display, keeping enough of the prefix and suffix that an operator can identify a credential in a log or UI without leaking the secret.
redact_partial_with
Partially redact s for display, keeping keep_first characters at the start and keep_last at the end. The middle is replaced by ***. The same edge cases as redact_partial apply, with one twist: when keep_first + keep_last is greater than the input length, the function falls back to full-mask ("***") to avoid leaking the entire secret.
