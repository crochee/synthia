synthia::workflow

Module spec 

Source
Expand description

The workflow document: what to run, as data.

A WorkflowSpec is ordered Steps. Four shapes cover the orchestration the reference script VM could express for a whole run:

  • Step::Agent — one agent, optionally gated.
  • Step::FanOut — N prompts under one agent, run concurrently.
  • Step::BestOf — N prompts under one agent, run concurrently; the host’s selection chooses the winner, by default the first success.
  • Step::Pipeline — stages in order, each stage’s text output feeding the next stage’s prompt.

Phases are optional labels over step ids, for reporting only: they never change execution order, and a document without them runs exactly the same.
