ToolSchemaBuilder — small builder for JSON-Schema with feature-gated field removal.

R29 (pi-subagents invocation-config.ts:isolationParam parity). The pi-subagents pattern: when a capability is not enabled, the corresponding field is removed from the LLM-facing schema — not just hidden behind a description. A refused parameter with a leftover description would teach the model the capability exists; a removed field is invisible.

ToolSchemaBuilder wraps a serde_json::Map<String, Value> and exposes .with, .without, .merge, and .build. Tools compute their schema as a normal serde_json::Value, then surgically remove fields based on a ToolFeatures value.
