pub fn create_worktree(

Expand description

Create a fresh detached worktree off the base cwd’s HEAD.

base_cwd is the directory the parent session was launched in; the worktree is a copy of that repo. runner issues the git calls so tests can swap in a fake. cancel is propagated to the runner but the worktree creation itself is not cancellable mid-flight (one git worktree add call).
