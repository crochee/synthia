Expand description

Run the gate exactly once and return the resulting verdict.

The function:

  1. Validates the argv and working directory.
  2. Spawns the gate via runner with cancel observed while waiting.
  3. On exit status 0 ⇒ GateVerdict::Pass.
  4. On non-zero exit ⇒ GateVerdict::Fail.
  5. On cancellation ⇒ GateVerdict::Killed.

The verdict is set by the FIRST outcome that completes; the caller never sees two verdicts and never needs to re-run the gate.
