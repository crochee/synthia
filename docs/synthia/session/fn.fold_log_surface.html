pub fn fold_log_surface(rows: &[Value]) -> FoldedSurface
Expand description

Fold a raw session log into the model-visible surface.

Every message-producing row — typed or legacy — becomes one surface row; the row’s seq is its 1-based position among the event rows. The sink’s metadata header (is_metadata_header_row) is not a row: it is skipped and consumes no ordinal, so a folded seq always equals the stream_index the sink assigned that event. A compaction row replaces the surface span it cites. A replacement that cannot be validated is skipped with a warning, so the caller always gets a usable surface.
