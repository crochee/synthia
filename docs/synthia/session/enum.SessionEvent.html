Expand description

One entry in the durable session event log.

seq is the monotonic ordinal assigned by the sink at append time. Callers MUST NOT pick seq manually — the sink stamps it on read() (returning events in the canonical order) and on fold_surface (which validates seq continuity).

The data payload on message-emitting variants is a JSON Value so the wire shape stays decoupled from synthia_provider::Message’s exact serialization (which may grow new content-part variants over time).

Usage

Per-call usage attribution — log-only.

R30: the provider report is carried in two shapes. The typed usage field is the current wire form (serde default, so pre-R30 rows parse with None); the legacy data payload (prompt_tokens / completion_tokens / cache_read_tokens / cache_write_tokens) is still stamped so older readers keep working. Read either shape through SessionEvent::provider_usage.

Fields

§seq: u64

Sequence ordinal.

§ts: String

ISO-8601 timestamp.

§data: Value

Epoch + token breakdown (legacy envelope).

§usage: Option<UsageBuckets>

Typed disjoint provider usage report (R30), absent on older rows.

§

SandboxMode

Session sandbox-mode override — log-only.

A policy switch (a UI control, a delegation seed, a test fixture) is recorded as one of these on the session it applies to. The log IS the store: the override survives a restart by replay, and two sessions can never see each other’s state (dsh sandbox/mode parity). The effective policy is the last such event folded against the caller’s grants and the deployment default — see synthia_tool_shell::sandbox::effective_policy.

Fields

§seq: u64

Sequence ordinal.

§ts: String

ISO-8601 timestamp.

§mode: String

Execution-policy wire name ("read-only" / "workspace-write" / "danger-full-access"). Carried as a string rather than an enum: a log written by a newer build must round-trip here, and a mode this build does not know is ignored by the policy fold.

§

LifecycleShutdown

Session shutdown lifecycle — log-only.

Emitted by the server’s SessionController::close after all child sessions have been signalled, so the log ends with an explicit, replayable shutdown marker.

Fields

§seq: u64

Sequence ordinal.

§ts: String

ISO-8601 timestamp.

§data: Value

Shutdown metadata (reason, child count, …).

pub fn provider_usage(&self) -> Option<UsageBuckets>

Provider usage reported by this event, if any.

SessionEvent::Usage rows carry the report either in the typed R30 usage field or — on pre-R30 rows — in the legacy data payload (prompt_tokens / completion_tokens / cache_read_tokens / cache_write_tokens). Both shapes resolve to the same disjoint UsageBuckets. Non-usage events, and usage rows without a decodable report, return None.

Source

pub fn sandbox_mode(&self) -> Option<&str>

Policy wire name carried by a SessionEvent::SandboxMode row, if this is one.

Returns the raw string, not a parsed policy: the wire layer does not know the policy enum, and an unknown mode must survive a read-back for a newer build to interpret.

Source

pub fn from_value(v: &Value) -> Option<SessionEvent>

Parse a SessionEvent from the opaque serde_json::Value produced by SessionSink::read. Returns None for legacy shapes that pre-date the typed layer ({"role": ...}, {"type": "UserInput"}, etc.) — callers handle those via the existing events_to_messages projection.
