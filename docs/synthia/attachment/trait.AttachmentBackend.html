Required Methods§

Source

fn save( &self, bytes: &[u8], mime_type: &str, ) -> Result<ImageAttachmentRef, AttachmentError>

Save bytes and return the canonical ref. The backend is responsible for content addressing (hash → bytes) and may dedup internally.

Source

fn read(&self, ref_: &ImageAttachmentRef) -> Result<Vec<u8>, AttachmentError>

Read the bytes for ref_. Returns NotFound if absent or HashMismatch if the stored bytes can’t be verified.
