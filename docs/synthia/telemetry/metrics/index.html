Prometheus RED (Rate / Errors / Duration) metrics + text exposition.

The HTTP request counters / histograms in HTTP_REQUESTS_TOTAL and HTTP_REQUESTS_DURATION_SECONDS are the canonical “what is this server doing” signal pulled by Prometheus scrapes against the /metrics endpoint. Labels (method, path) are taken from the matched axum route template (not the raw request URI), so a high-cardinality path like /api/v1/chat/sessions/{id}/messages collapses to a single time series regardless of how many distinct session ids are queried.

§Lazy registration

The vectors register lazily on first dereference (via lazy_static) and emit no families until a labeled child is created — prometheus::gather() drops childless families, so a scrape between boot and the first tracked request is empty by design (Prometheus treats it as no data, not an error).

Structs§

HTTP_REQUESTS_DURATION_SECONDS
Per-endpoint request latency histogram in seconds, labeled by method and matched path. Buckets cover the 5 ms … 10 s range — anything outside that window falls into +Inf and is still exported.
HTTP_REQUESTS_TOTAL
Total number of HTTP requests, labeled by method and matched path.
TOOL_EXECUTIONS_TOTAL
Per-tool execution outcome counter (R5-6). outcome is one of ok / error / panic / truncated. truncated means the tool succeeded but the result was bound to a smaller window by the truncator; the original is still on disk under the spill dir.
TOOL_EXECUTION_DURATION_SECONDS
Per-tool execution duration histogram (R5-6). Buckets cover the 1 ms … 60 s range — anything outside falls into +Inf and is still exported.
TOOL_PANICS_TOTAL
Total number of tool executions that panicked (R5-6). Labelled by tool name. The synthesised ToolOutput::error that consume_tool_stream_into emits on panic also increments tool_executions_total{outcome="panic"}.
TOOL_TRUNCATIONS_TOTAL
Total number of tool results truncated by the OutputBound policy (R5-6).

Functions§

gather_text
Encode all registered Prometheus metric families into the standard text exposition format. Returns the serialized text ready to ship as a Content-Type: text/plain; version=0.0.4 response body.
record_tool_duration
Observe a tool execution’s wall-clock duration (R5-6).
record_tool_outcome_metric
Increment the per-tool ok / error counter (R5-6). outcome = "ok" when is_error = false, outcome = "error" otherwise. Note the panic case has its own counter (record_tool_panic) and is incremented there only.
record_tool_panic
Increment the per-tool panic counter (R5-6). Called from consume_tool_stream_into after a panicking tool’s AssertUnwindSafe + catch_unwind produces a synthetic error result.
record_tool_truncation
Increment the per-tool truncation counter (R5-6). Called from the truncator when OutputBound clips a result.
