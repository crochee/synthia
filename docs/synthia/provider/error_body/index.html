Structured provider HTTP error bodies.

pi packages/ai/src/utils/error-body.ts parity (R33).

Both adapters store the raw HTTP body of a failed request in synthia_core::Error::RequestFailed, which already keeps the status and the body together. parse_provider_error_body unwraps the shapes providers actually send — OpenAI’s {"error": {"type", "code", "message"}}, the flat {"type", "message"} some gateways return, and a non-JSON body — so crate::retry::classify_provider_error_body can read the provider’s own type / code instead of guessing from substring markers, and so a caller can show the provider’s message instead of a raw JSON blob.
