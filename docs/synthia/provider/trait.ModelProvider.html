fn tier(&self) -> ModelTier

Cheap, sync tier resolution for steering + adaptive registry callers. R10 default derives the tier from the model config’s context_window (>= 100K -> Large, >= 32K -> Medium, else Small). Providers can override to thread additional signals (e.g. Anthropic Claude 3 Haiku stays Small even with a 200K context).

fn complete_with_stream<'life0, 'async_trait>( &'life0 self, request: CompletionRequest, cancel_token: Option<Arc<dyn CancelToken>>, on_delta: Box<dyn FnMut(StreamChunk) + Send>, ) -> Pin<Box<dyn Future<Output = Result<CompletionResponse, Error>> + Send + 'async_trait>>
where 'life0: 'async_trait, Self: 'async_trait,

Callback-based streaming completion.

cancel_token allows the caller to abort an in-flight stream (5-second default grace is enforced by the Anthropic implementation to flush the underlying HTTP body). The default implementation calls complete() and emits a single StreamChunk::IsDone carrying the resulting SamplingResult. Providers that support real streaming may override this to emit incremental deltas (Content / ToolCallDelta / Usage / etc.) and the terminal IsDone chunk. See StreamChunk for the event vocabulary.

fn embed<'life0, 'async_trait>( &'life0 self, texts: Vec<String>, ) -> Pin<Box<dyn Future<Output = Result<Vec<Vec<f64>>, Error>> + Send + 'async_trait>>
where 'life0: 'async_trait, Self: 'async_trait,

Generate dense vector embeddings for a list of text strings. Returns a list of embedding vectors (Vec<Vec<f64>>), one per input text and in the same order.

The default impl returns an empty vector for every text. Providers that support dense embeddings override this; providers that have no embedding endpoint do not need to write the no-op body — the default keeps the trait usable for providers that never embed.
