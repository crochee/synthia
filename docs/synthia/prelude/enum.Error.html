Expand description

Top-level Synthia error. Returned by every fallible operation across the workspace.

  • Display (generated by thiserror) is the single-line human message; the HTTP layer logs it and copies it into the response envelope’s message field.
  • The stable snake_case wire code for telemetry tags, log fields, and the envelope’s code field is assigned at the transport boundary (synthia_server::api::error); core owns the variant taxonomy, not the encoding.
  • std::error::Error::source routes through the #[from] / #[source] payload fields (Io, RetryExhausted) so the original cause stays reachable.

Variants (Non-exhaustive)§

This enum is marked as non-exhaustive
Non-exhaustive enums could have additional variants added in future. Therefore, when matching against variants of non-exhaustive enums, an extra wildcard arm must be added to account for any future variants.
