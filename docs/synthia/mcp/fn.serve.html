Serve tools over the loopback inbox until the client side drops.

The caller owns the task this future runs on — nothing here spawns, so a lib consumer on any runtime (or a test) decides the lifetime. Every envelope gets a response; a handler panic or a malformed envelope degrades to a JSON-RPC error, never a hung request slot.
