pub fn resolve_prefix(public: &str) -> Option<(&str, &str)>
Expand description

Split a namespaced public name back into (server, raw).

"mcp__fs__read_file" → ("fs", "read_file"). Returns None for names without the mcp__<server>__<raw> shape. The split takes the first __ after the marker, so a raw part that itself contains __ round-trips exactly, while a server name containing __ cannot (avoid such server names). Lossy names carry a _hash suffix that belongs to the raw part — use this to attribute a name to its server, not to recover the exact raw spelling.
