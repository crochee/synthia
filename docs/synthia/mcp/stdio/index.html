McpTransport over a child process’s stdin/stdout.

Spawns command args…, writes newline-delimited JSON-RPC 2.0 requests to the child’s stdin, and reads one response line per request from its stdout. stderr is inherited so server logs reach the operator.

kill_on_drop(true) guarantees the child dies with the transport — a dropped client never leaks an MCP server.
