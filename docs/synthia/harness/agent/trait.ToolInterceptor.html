Expand description

A synthetic tool the loop dispatches ahead of the registry.

Install with ReActAgent::with_interceptor. The loop advertises definitions alongside the registry’s tools (subject to the same tool restriction) and routes any call whose name an interceptor claims to execute instead of the registry.
