Agent lifecycle events.

§Module Layout

  • event_enum: the top-level event_enum::AgentEvent enum with four variants (Model / ModelDone / System / Agent).
  • system_event: the system_event::SystemEvent enum + system_event::WarningKind for lifecycle and diagnostic events (session start/end, progress, warnings, recovery, usage).
  • agent_meta: the agent_meta::AgentMeta struct describing a subagent’s parent / child relationship.
  • reasons: reasons::SessionEndReason (terminal reason).
