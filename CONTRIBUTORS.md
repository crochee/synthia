# Contributors

Synthia is built by the people listed below and by the larger
community who report issues, review PRs, file bug reproductions,
write specs, and keep the documentation honest. Thank you.

This file follows the CNCF community convention: it is generated
from the git history (`git shortlog -s -n`) and never hand-edited
beyond the "Emeritus / past maintainers" section. To add yourself
when you land a non-trivial PR, run:

```bash
git log --author="Your Name" --oneline | head
# if the commit author doesn't match your GitHub handle, ask a
# maintainer to run `make contributors-update` (see Makefile).
```

If a contributor would rather not be listed here, that is also
fine — open an issue or contact a maintainer privately.

## Active maintainers

See [`MAINTAINERS.md`](MAINTAINERS.md) for the people who can land
PRs and their per-area responsibility. Maintainers are listed there
rather than here so that the two files do not drift.

## All contributors

The canonical, up-to-date list is generated by:

```bash
git shortlog -s -n --all
```

If the output below looks stale (for example, a recent merge did not
appear), regenerate it with `make contributors-update` (which is a
thin wrapper over `git shortlog -s -n --all | awk '{printf "- %s\n",
$0}'`).
