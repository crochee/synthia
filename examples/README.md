## Examples of how to use synthia

This directory contains a number of examples showcasing various capabilities of
the `synthia` crates.

All examples can be executed with:

```sh
cargo run --package synthia-examples --example $name
```

All examples enable logging via `RUST_LOG`. To enable deeper logging of the `synthia` crates you can do:

```sh
RUST_LOG=info cargo run --package synthia-examples --example $name
```
