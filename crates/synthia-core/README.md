# synthia-core

Common utilities for the Synthia AI Agent framework.

## Features

- **Error**: the single cross-crate `Error` enum — a plain
  thiserror enum (per-variant `#[error]` Display, `#[from]` /
  `#[source]` source routing) with one-line helper constructors
  and a stable snake_case wire code (`Error::kind()`). Every
  workspace crate re-exports it; the HTTP boundary lives in
  `synthia-server` (`ApiError` adapter).
- **Registry**: generic registry with cursor pagination
  (`Registry`, `RegistryItem`, `paginate_registry_list`).
- **Sensitive**: `Sensitive`/`SensitiveData` redaction for
  secret-bearing values.
- **Text**: `cap_to_char_boundary` UTF-8 safe truncation.
- **Token**: `estimate_token_count` heuristic (ASCII/CJK) for
  pre-flight budget checks.

## Usage

```rust
use synthia_core::Error;

let err = Error::not_found("session");

// Display is generated by thiserror.
assert_eq!(err.to_string(), "not found: session");

// Wire-level error code lives at the server boundary
// (`synthia_server::api::AppError`); this crate only owns the
// domain enum, its Display, and its source-chain routing.
```
