# ContextInject Tools

上下文注入工具模块，提供将上下文信息注入到对话中的能力。

## 工具列表

| 工具名称 | 功能描述 |
|----------|----------|
| `ContextInject` | 从环境变量注入自定义上下文 |

## 交互顺序

```
Agent → 注入上下文 → 对话包含上下文 → 继续推理
```

## 在 Agent 中的作用

1. **动态上下文**: 运行时注入额外信息
2. **环境变量**: 从环境变量读取上下文（MOIM_MESSAGE_TEXT / MOIM_MESSAGE_FILE）
3. **提示补充**: 为 LLM 提供额外背景信息

## 使用示例

```json
{
  "name": "ContextInject",
  "arguments": {}
}
```

## 设计理念

> 上下文是推理的燃料

ContextInject 系统解决的问题：
1. **动态注入**: 运行时添加上下文
2. **环境集成**: 读取环境变量
3. **灵活补充**: 按需提供额外信息
