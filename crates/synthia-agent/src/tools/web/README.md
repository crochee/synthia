# Web Tools

网络工具模块，提供网络搜索和网页抓取能力，扩展 Agent 的信息获取渠道。

## 工具列表

| 工具名称 | 功能描述 |
|----------|----------|
| `web_search` | 网络搜索 |
| `web_fetch` | 获取网页内容 |

## 交互顺序

```
Agent → 发起网络请求 → 获取结果 → 处理返回 → 继续推理
```

## 在 Agent 中的作用

1. **信息检索**: 通过搜索引擎获取信息
2. **网页抓取**: 获取指定网页内容
3. **知识补充**: 获取最新信息和文档
4. **实时数据**: 获取实时数据

## 使用示例

### 网络搜索

```json
{
  "name": "web_search",
  "arguments": {
    "query": "Rust 异步编程最佳实践"
  }
}
```

### 获取网页

```json
{
  "name": "web_fetch",
  "arguments": {
    "url": "https://doc.rust-lang.org/book/"
  }
}
```

## 设计理念

> 知识就是力量

Web 系统解决的问题：
1. **信息获取**: 扩展知识来源
2. **实时数据**: 获取最新信息
3. **文档访问**: 访问在线文档
4. **研究支持**: 支持深度研究任务
