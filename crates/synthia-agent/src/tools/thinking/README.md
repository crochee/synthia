# Thinking Tools

结构化思考工具模块，提供分步推理能力，帮助 Agent 进行复杂问题的分析和解决。

## 工具列表

| 工具名称 | 功能描述 |
|----------|----------|
| `sequentialThinking` | 分步思考 |

## 交互顺序

```
Agent → 定义问题 → 分步思考 → 逐步推理 → 得出结论
```

## 在 Agent 中的作用

1. **分步推理**: 将复杂问题分解为步骤
2. **深度分析**: 逐步深入分析问题
3. **逻辑验证**: 验证推理过程
4. **结论总结**: 汇总推理结果

## 使用示例

```json
{
  "name": "sequentialThinking",
  "arguments": {
    "thought": "分析这个问题...",
    "nextThought": "基于上一步...",
    "thoughtNumber": 1,
    "totalThoughts": 3,
    "isFinal": false
  }
}
```

## 设计理念

> 思考需要结构化

Thinking 系统解决的问题：
1. **复杂问题**: 将复杂问题分解处理
2. **推理透明**: 展示推理过程
3. **逻辑清晰**: 逐步验证推理
4. **结果可靠**: 通过结构化提高质量
