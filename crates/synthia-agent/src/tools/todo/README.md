# Todo Tools

任务规划工具模块，提供结构化的任务列表管理能力，帮助 Agent 进行复杂任务规划。

## 工具列表

| 工具名称 | 功能描述 |
|----------|----------|
| `todoWrite` | 管理任务列表 |

## 交互顺序

```
Agent → 创建任务列表 → 渲染展示 → Agent 继续推理
```

## 在 Agent 中的作用

1. **任务规划**: 将复杂任务分解为步骤
2. **状态追踪**: 跟踪任务进度
3. **依赖管理**: 处理任务间依赖关系
4. **并行化**: 支持无依赖任务的并行执行

## 任务状态

- `pending`: 待处理
- `in_progress`: 进行中
- `completed`: 已完成
- `cancelled`: 已取消

## 使用示例

```json
{
  "name": "todoWrite",
  "arguments": {
    "todos": [
      {"id": "1", "content": "设计数据库结构", "status": "completed"},
      {"id": "2", "content": "实现 API 接口", "status": "in_progress", "deps": ["1"]},
      {"id": "3", "content": "编写测试用例", "status": "pending", "deps": ["2"]}
    ]
  }
}
```

## 设计理念

> 复杂工作需要结构化规划

TodoWrite 解决的问题：
1. **步骤拆分**: 将复杂任务分解为可管理的小步骤
2. **进度追踪**: 清晰了解任务完成情况
3. **依赖管理**: 处理任务间的阻塞关系
4. **并行优化**: 自动识别可并行执行的任务
