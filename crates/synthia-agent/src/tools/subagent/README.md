# Subagent Tools

子代理工具模块，提供创建隔离子代理的能力，子代理拥有独立的上下文。

## 工具列表

| 工具名称 | 功能描述 |
|----------|----------|
| `spawn_agent` | 创建子代理 |

## 交互顺序

```
Agent → 创建子代理 → 独立执行 → 返回结果 → 子代理结束
```

## 在 Agent 中的作用

1. **隔离执行**: 子代理拥有独立上下文，不继承父代理历史
2. **专注任务**: 用于处理需要独立思考的子任务
3. **资源管理**: 限制同时运行的子代理数量
4. **上下文注入**: 支持传递额外上下文

## 使用示例

```json
{
  "name": "spawn_agent",
  "arguments": {
    "subagent": "code-reviewer",
    "prompt": "请审查这段代码的实现逻辑",
    "context": "相关代码文件路径..."
  }
}
```

## 与 Team 的区别

| 特性 | Subagent | Team |
|------|----------|------|
| 上下文 | 独立隔离 | 共享 |
| 生命周期 | 临时 | 持久 |
| 用途 | 单次任务 | 长期协作 |

## 设计理念

> 隔离带来专注

Subagent 系统解决的问题：
1. **上下文隔离**: 保持主对话简洁
2. **专注思考**: 子任务独立处理
3. **资源控制**: 限制并发数量
4. **灵活传递**: 可注入额外上下文
